# 🦉 אוֹתִיּוֹת וְקַסְמִים - לומדים לקרוא בכיף (כיתות א׳-ב׳)

אפליקציית ווב אינטראקטיבית, עשירה ומרהיבה ללימוד ותרגול מיומנויות קריאה בעברית לילדים בראשית קריאה (כיתות א'-ב' והכנה לכיתה א').

האפליקציה פותחה בהתאם לעקרונות הפדגוגיים של הוראת השפה העברית ורכישת הקריאה (מודעות פונולוגית, זיהוי אותיות, תנועות הניקוד, מיזוג הברתי, שטף קריאה והבנת הנקרא).

---

## 🌟 עיקרי האפליקציה

1. **🏰 מַמְלֶכֶת הָאוֹתִיּוֹת וְהַצְּלִילִים**:
   - כרטיסיות לכל 27 אותיות האלף-בית (כולל אותיות סופיות: ך, ם, ן, ף, ץ).
   - השמעת שם האות והצליל שלה בהקראה קולית ברורה.
   - מילה מדגימה עם איור ורמז זיכרון ידידותי לילדים.
   - סינון מהיר: כל האותיות, אותיות רגילות, אותיות סופיות.

2. **👑 אֶרֶץ הַתְּנוּעוֹת וְהַנִּיקּוּד**:
   - היכרות מונפשת ומדויקת עם כל תנועות השפה העברית:
     - קָמָץ וּפַתָּח (A)
     - חִירִיק (I)
     - חוֹלָם (O)
     - שׁוּרוּק וְקֻבּוּץ (U)
     - סֶגוֹל וְצֵירֵה (E)
     - שְׁוָא (עצירה / חצי תנועה)
   - הסברים מוחשיים המותאמים לגיל הילד (למשל: תנועת הפה "לפתוח פה גדול כמו אצל הרופא: אָה!").
   - שבבי תרגול קוליים לשמיעת צלילי אותיות עם הניקוד הספציפי.

3. **🧩 מַעְבֶּדֶת הַהֲבָרוֹת וְהַמִּילִים (Word & Syllable Builder)**:
   - תרגול מיזוג הברתי ופירוק מילים (למשל: `[בָּ]` + `[לוֹן]` = `בָּלוֹן`).
   - לחיצה על הברות בסדר הנכון מתוך בנק אפשרויות הכולל מסיחים.
   - משוב קולי מיידי, חיזוק חיובי, חגיגת קונפטי וצבירת כוכבים.

4. **🫧 אֲתַגַּר פִּצּוּץ הַבּוּעוֹת (Bubble Popper Challenge)**:
   - משחקון זריזות וזיהוי שמיעתי-חזותי: הילד שומע צליל (למשל: "מָּה!" או "לִי!") וצריך לפוצץ את הבועה המרחפת המתאימה לפני שהיא עולה לשמיים.
   - אימון מעולה על מהירות תגובה ודיוק פונולוגי.

5. **📚 סִפְרִיַּת הַקְּרִיאָה הַמְּדֹרֶגֶת לְפִי שִׁלְבֵּי הַנִּיקּוּד**:
   - חלוקה פדגוגית שיטתית ומדויקת המותאמת להוראת הקריאה בישראל:
     - **שָׁלָב 1 • רַק קָמָץ וּפַתָּח (אָ, אַ)**: כל המילים בקטע מורכבות אך ורק מתנועות קמץ ופתח ("דָּן וְסַבָּא בַּגַּן"). מתאים במיוחד לראשית הקריאה!
     - **שָׁלָב 2 • הוֹסָפַת חִירִיק (אִי)**: משפטים המשלבים קמץ, פתח ותנועת חיריק ("אִמָּא וְדִינָה שָׁרוֹת שִׁיר").
     - **שָׁלָב 3 • הוֹסָפַת חוֹלָם (אוֹ)**: הוספת תנועת חולם ומילים מוכרות ("יוֹסִי וְהַבָּלוֹן הָאָדֹם").
     - **שָׁלָב 4 • הוֹסָפַת שׁוּרוּק וְקֻבּוּץ (אוּ)**: הוספת תנועת שורוק וקובוץ ("הַחָתוּל וְהַכַּדּוּר שֶׁל גּוּר").
     - **שָׁלָב 5 • הוֹסָפַת סֶגוֹל וְצֵירֵה (אֶ, אֵ)**: השלמת כל תנועות העברית ("הַיֶּלֶד וְהַכֶּלֶב תַּחַת הָעֵץ").
     - **שָׁלָב 6 • קְרִיאָה שׁוֹטֶפֶת לְכִתָּה ב׳**: סיפור הרפתקאות מלא עם עברית עשירה ומורכבת ("מַסָּע אַל הַיָּרֵחַ וְהַכּוֹכָבִים").
   - **כפתורי סינון מהירים**: אפשרות לסנן ולבחור את שלב הניקוד המבוקש.
   - **הקראה קולית מונחית (קריוקי)**: מילים מודגשות בזמן אמת בעת ההקראה.
   - **קריאה עצמאית**: לחיצה על כל מילה בודדת משמיעה את הגייתה המדויקת אם הילד נתקע.
   - **שאלות הבנת הנקרא**: שאלה אינטראקטיבית בסוף כל סיפור המעודדת הפקת לקחים והבנה.

6. **🏆 אַלְבּוֹם הַמַּדְבְּקוֹת וְהַהִישָּׂגִים (Gamification & Rewards)**:
   - צבירת כוכבים על כל הצלחה.
   - פתיחת 9 מדבקות וירטואליות יוקרתיות (כוכב הקריאה, נסיך הניקוד, טייס חלל ועוד).
   - שמירה מקומית מלאה (LocalStorage) - הכוכבים וההישגים של הילד נשמרים תמיד!

## ♿ נגישות והתאמה אישית לילדים

- **גופן מותאם לקריאה וניקוד מושלם**: מעבר לגופנים העבריים **Assistant** ו-**Alef** הכוללים תמיכת OpenType Mark Positioning מלאה (`font-feature-settings: "mark" 1, "mkmk" 1`), המציגים כל נקודה, קמץ, פתח, חיריק ודגש בדיוק מוחלט מתחת ומעל לאות ללא עיוותים או חפיפות.
- **מרווח שורות נדיב (Line Height)**: מרווח שורות מוגדל (2.6) המונע חיתוך של תנועות עליונות ותחתונות ומאפשר קריאה נוחה וקלה לעיניים צעירות.
- **הדגשת ניקוד בצבע (🎨)**: אפשרות לצביעת סימני הניקוד בגוון אדום/ורוד בולט, המפריד חזותית בין גוף האות לבין התנועה.
- **הגדלת גופן (Aa)**: אפשרות בלחיצת כפתור להגדיל את כל הטקסטים והאותיות באפליקציה ב-15% ו-30%.
- **הקראה קולית במבטא עברי טבעי וישראלי (🗣️)**: סינון קפדני החוסם קולות זרים (כמו en-IL) ומציע קולות טבעיים באיכות פרימיום (Microsoft Avri Natural, Hila, Google עברית). כולל מודאל בחירת קול וכפתור בדיקה להשמעה מיידית!
- **נרמול פונטי חכם (Phonetic Normalization)**: מנועי דיבור עבריים קוראים טקסט במבטא שוטף וטבעי, בעוד שתווי ניקוד מסוימים גורמים למנועים שונים לגמגם; המערכת מנרמלת את התוכן להגייה ישראלית חלקה ומדויקת להפליא.
- **השתקת / הפעלת קול (🔊/🔇)**: שליטה מלאה בצלילי המשחק וההקראה.
- **התאמה אישית של שם הילד/ה (👤✏️)**: הזנת שם הילד/ה בכניסה הראשונה או בכל עת דרך סרגל הראש. הינשוף "קראי" פונה לילד/ה בשמם הפרטי בקול ובכתב, והשם מוטמע בתעודות ההצטיינות ובאלבום המדבקות!
- **בחירת דמות אישית**: הילד בוחר את האווטאר המועדף עליו (👦, 👧, 🦁, 🦊, 🤖, 🦉).

## 🛠️ טכנולוגיה ומבנה הפרויקט

האפליקציה בנויה ב-**Pure Web Technologies (Vanilla HTML5 / Modern CSS3 / ES6+ JavaScript)**:
- **ללא ספריות כבדות וללא תלות ברשת**: עובדת מיד במצב לא מקוון (Offline).
- **Web Audio API**: סינתיסייזר מובנה לצלילי פיצוץ בועה, כוכבים, צלילי הצלחה וצהלת ניצחון.
- **Web Speech API**: מנוע דיבור מובנה לדוברי עברית (`he-IL`) להקראת אותיות, מילים ומשפטים.
- **Canvas Confetti**: מנוע חלקיקי קונפטי קל-משקל וחגיגי לחגיגת הישגים.

```
hebrew-reading-app/
├── index.html          # שלד הדף, ממשק המשתמש, מודאלים ולשוניות
├── style.css           # סגנונות עיצוב, פלטת צבעים ילדותית ואנימציות
├── reading-data.js     # מאגר התכנים הפדגוגי (אותיות, ניקוד, מילים, סיפורים ומדבקות)
├── sound-effects.js    # מנוע צלילים (Web Audio API) והקראה קולית בעברית
├── app.js              # לוגיקת המשחק, ניהול מצבים, כוכבים ואלבום מדבקות
└── README.md           # מדריך שימוש והסברים פדגוגיים
```
